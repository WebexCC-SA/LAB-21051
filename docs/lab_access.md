# dCloud Access

We are using Cisco eXpo for this lab. Click on the [Expo Link](https://FIXME)

**1.** We have assigned you to a tenant to use for this session. Select the **Explore** button that corresponds to your tenant.

   ![eXpo Start Page](./assets/lab_access/101a.png)

<br>

**2.** Enter your email, then check the box to accept the dCloud Terms & Conditions. When you have done this, select **Continue**.

   ![Terms and Conditions](./assets/lab_access/102a.png)

<br>

**3.** A session is now assigned for you to continue with. Select the **Remote Desktop** link next to WKST1 to open the jump box we will use for the entire lab.

   ![Session Start](./assets/lab_access/103a.png)

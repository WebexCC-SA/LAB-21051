# Overview

### **Learning Objectives**

This lab will give you an introduction to the new AI features for Contact Center Enterprise introduced in version 15.0.


You will see and use the following features:

**1.** Webex AI Agent - Autonomous

**2.** Webex Common Identity

**3.** Webex AI Assistant

- *Virtual Agent Transfer Summary*
- *Call Transcript*
- *Real-Time Assist*
- *Wrap-Up Summary*

### **Lab Flow**

In the session, you will work with an AI Agent and see the new features of local fulfillment for an AI Agent. 

Next, you will provision a Common Identity (CI) user to your session. You will see the flow for the new authentication method for CCE.

Finally, you will see the new AI Assistant feature and see how it can make your customer's lives so much better.
